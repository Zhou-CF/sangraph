# Role

# Goal
请基于目标防御代码、结构化逻辑、RAG 参考案例和可用的代码上下文，判断该防御是否可能失效。

{SANITIZER_LOGIC}

3. RAG 参考案例：
{RAG_CONTEXT}

4. RAG 参考性评估：
{RAG_RELEVANCE}

5. 额外上下文：
{INPUT_CONTEXT}

# Public Evidence Policy
{PUBLIC_EVIDENCE_POLICY}

# Rules
- 只有在 RAG 参考性偏低时，才允许补充公开资料证据。
- 公开资料仅限公开补丁、CVE、安全公告、官方文档或可信安全分析。
- 不要输出利用代码、攻击步骤或可直接复现的 payload；只能总结防御为何可靠或为何可能失效。
- 如果公开资料不可用，请明确写在 `external_evidence_reason` 中。
- 可以进行代码运行来尝试绕过这个sanitizer，这样的绕过可行性的准确度会高很多
